# Betterware Control de Pedidos

Aplicación original de control de clientes y pedidos Betterware, preparada para Android con Capacitor.

## Generar el APK desde GitHub

1. Abre la pestaña **Actions**.
2. Selecciona **Build Android APK**.
3. Pulsa **Run workflow**.
4. Espera a que finalice la compilación.
5. Descarga **Betterware-Control-Pedidos-APK** desde Artifacts.

El resultado es un APK de depuración para instalar y probar en Android.

## Datos

Los clientes y pedidos se guardan localmente en el dispositivo. Los datos del navegador no se transfieren automáticamente a la app instalada. Exporta un respaldo JSON desde la versión actual y restáuralo en la app instalada.
